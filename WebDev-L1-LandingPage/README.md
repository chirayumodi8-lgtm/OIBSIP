
# BrightSpace - Landing Page

## About the Project
BrightSpace is a responsive landing page created as part of my Oasis Infobyte Web Development Internship.

The website presents creative digital services through a clean layout and simple navigation.

## Features
- Responsive navigation bar
- Hero section with a call-to-action button
- Features section with three cards
- About and Contact sections
- Responsive layout for mobile screens
- Consistent colours and typography

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid concepts are not required for this layout
