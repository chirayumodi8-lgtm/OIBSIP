
# Temperature Converter

## About the Project
This is a simple temperature converter website created as part of my Oasis Infobyte Web Development Internship.

## Features
- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Input validation
- Responsive design
- Error message for temperatures below absolute zero

## Technologies Used
- HTML5
- CSS3
- JavaScript
